## 2. Evidence Set 内部对比

| 设置 | Page Recall | Region Hit |
|---|---:|---:|
| Top1 single node | 0.1562 | 0.1562 |

## 6. 结论

1. `Evidence Set Region` 的 Region Hit@5 高于两个 single-node baseline，说明候选池合并和覆盖度选择有效。
2. Top3 evidence set 已经接近 Top5 输出，说明主要收益来自最小证据集，而不是单纯增加返回数量。
3. 仍有较大 Oracle gap，说明后续要继续提升候选池质量和证据充分性判断，尤其是财务表格中同指标多处出现造成的干扰。
4. 下一步应做 evidence set 充分性评价：判断返回的证据集合是否同时覆盖“指标、年份、单位、数值”。
