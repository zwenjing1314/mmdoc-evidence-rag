# 实验记录使用规则

> Status: working | Scope: 过程记录 | SSOT: `experiments/registry.csv`

- 一次正式 run 在 `experiments/registry.csv` 加一行（唯一注册表）；
- 详情用 `experiments/templates/experiment-record.md`（11 段模板）在 `experiments/` 下新建 `YYYY-MM-DD-exp-NNN-主题.md`；
- 只增不改，不删旧记录；
- 本目录不再新增详情页，详情页统一放 `experiments/`（第 5 步起生效），本 README 保留作为过渡指引，第 6 步归档时一并处理。
