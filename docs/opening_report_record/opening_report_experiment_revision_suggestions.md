## 可直接粘贴版本

```text
（三）前期实验基础与初步实验结果

为避免研究停留在方案设计层面，本文在开题前已围绕中文上市公司年度报告构建了一个小规模实验闭环，用于验证多粒度证据表示、页面级检索和区域级证据定位的可行性。当前实验以 20 份公开中文年度报告 PDF 为对象，完成了从原始 PDF 解析、页面文本抽取、细粒度证据节点切分、问答标注构建、检索实验到指标评价的完整流程。

在数据处理方面，本文首先使用 PyMuPDF 对中文年度报告进行逐页解析，将每份 PDF 转换为页面级文本记录；随后根据页面文本块、财务指标行和疑似表格块，将文档进一步切分为段落节点、表格块节点和表格行节点。经过处理后，当前中文年报实验数据共包含 20 份年度报告、5327 个页面和 99304 个细粒度证据节点。其中，证据节点包括 paragraph、table_block 和 table_row 三类，用于支持页面级检索和区域级证据定位。

在问答标注方面，本文构建并人工修订了 160 条中文年报问答样本，问题覆盖报告年度、报告标题、营业收入、归属于上市公司股东的净利润、经营活动产生的现金流量净额、研发投入或研发费用、资产总额、风险文本和营业收入同比变化等类型。针对财务数值问题，标注中不仅记录标准答案，还补充了 answer_unit、value_evidence_text、unit_evidence_text、evidence_pages 和 evidence_node_ids 等字段，以保证答案数值、单位和证据来源均可复核。人工修订后，160 条问题均可回答，且全部成功映射到真实细粒度证据节点，未出现证据节点缺失情况。

在实验方法方面，本文已实现并比较了三类检索方法。第一类是 BM25-page，即传统关键词页级检索方法，用作基础 baseline；第二类是 Dense-page，即页级语义检索方法，在当前离线环境下采用 TF-IDF fallback 作为可复现实现；第三类是 Page -> Region 两阶段检索方法，即先进行页面级粗召回，再在候选页面内进行段落、表格块和表格行级细粒度检索。实验评价采用 Page Recall@k、MRR、nDCG@k 和 Region Hit@k 等指标。

初步实验结果如表 4 所示。

表 4 中文年报前期检索实验结果

方法        Page Recall@1  Page Recall@5  Page Recall@10  MRR     nDCG@5  Region Hit@5
BM25-page   0.0437         0.1625         0.2437          0.0932  0.0398  0.0000
Dense-page  0.1938         0.2687         0.3187          0.2247  0.1080  0.0000
Page -> Region 0.1938     0.2625         0.2625          0.2183  0.1070  0.2000

从结果可以看出，BM25-page 作为关键词检索 baseline 效果较弱，说明中文年度报告中的财务问题并不能完全依靠关键词匹配解决。Dense-page 在 Page Recall@1、Page Recall@5、Page Recall@10 和 MRR 等页级指标上明显优于 BM25-page，说明语义检索或语义相似度建模对长文档页面召回具有较大帮助。Page -> Region 方法的页级指标接近 Dense-page，同时能够返回具体证据节点，Region Hit@5 达到 0.2000，说明“页面级粗召回—区域级细定位”的两阶段思路在中文年报场景中具有可行性。

上述前期实验表明，本文研究不是仅停留在理论设想阶段，而是已经完成了真实中文长文档数据处理、标准化证据表构建、人工修订问答标注、基线检索实验和细粒度证据定位评估。后续研究将在该实验闭环基础上进一步引入更强的中文向量模型、多模态视觉检索、表格结构化切分、证据增强生成和可信性验证机制。
```


不要写成：


## 4. 结果指标要解释清楚

建议解释为：

```text

```

这比单纯说“效果很好”更可信。
