# 4 实验设置与结果分析

## 4.1 实验问题

本文不评估端到端答案生成，而评估已知所属文档条件下的证据定位。实验围绕四个问题展开：

1. 在中文年报中，BM25、稠密检索与二者融合的页面检索具有怎样的页面覆盖能力？
2. 在相同的文档内搜索范围下，多源候选与 Evidence Set 选择能否改善细粒度证据节点定位？
3. 数值扫描、槽位覆盖和混合节点粒度对规则式证据充分性有何影响？
4. 页面与布局节点检索组件在 MMDocIR 外部数据上的表现及适用范围如何？

页面方法输出页面，节点方法输出段落、表格块或表格行。因此，页面级和节点级结果分表报告，不将两种输出粒度的 MRR 或 nDCG 直接横向比较。

## 4.2 数据集、划分与实验协议

### 4.2.1 中文年报问答数据

主实验使用人工修订的中文年报问答标注。每条记录含所属公司年报、问题、答案、金标证据页面和细粒度证据节点；部分数值问题还含年度、单位和原始数值。为减弱同一公司的页面模板、报表写法和表格结构同时出现在训练与测试中的影响，数据按公司而非按问题划分。

| 划分 | 公司数 | 问题数 | 用途 |
| --- | ---: | ---: | --- |
| train | 12 | 96 | 候选规则开发与问题分析 |
| dev | 4 | 32 | 固定候选来源、Top-K 和选择策略 |
| test | 4 | 32 | 冻结后的最终报告 |

测试集公司清单和 `qa_annotations_v2_reviewed.csv` 的 SHA-256 均已冻结。所有最终对比和消融均使用同一 test 集；完整方法的候选来源、权重、Top-K 与选择策略在 dev 集确定后固定，未依据 test 结果修改。

### 4.2.2 MMDocIR 外部验证数据

MMDocIR Evaluation 数据[9]包含 313 篇长文档、20,395 页、170,338 个布局节点和 1,658 个问题。每个问题均有页面级金标，其中 1,598 个问题可精确映射到布局节点。该数据上的搜索范围同样限定为问题所属文档内，因此它验证的是文档内页面或布局证据定位，而非跨文档检索或端到端多模态问答。

## 4.3 实现与对比方法

中文年报实验的稠密编码器为 `BAAI/bge-small-zh-v1.5`，最大序列长度为 128，批大小为 8；不进行模型微调。页面检索和节点检索均在问题所属文档内执行。Evidence Set Region 的页面候选数为 10，全局节点候选数和数值扫描候选数均为 20，最终返回 5 个排序节点。其贪心选择阶段最多优先选择 3 个覆盖互补的核心节点；若不足 5 个输出，后续位置由高分候选补齐。

页面级对比包括：

| 方法 | 说明 |
| --- | --- |
| BM25-page | 页面文本的词法检索基线 |
| Dense-page | 基于 BGE 中文编码器的页面稠密检索 |
| Hybrid-page | 融合 BM25 与 Dense 的页面排序 |

节点级对比包括：

| 方法 | 说明 |
| --- | --- |
| Page -> Region | Dense 页面召回后，在候选页面内进行 Dense 节点检索 |
| Hybrid-Page -> Region | 以 Hybrid 页面候选替换 Dense 页面候选 |
| Global-Region | 直接在同一文档的全部节点中进行 Dense 检索 |
| Evidence Set Region | 多源候选、数值扫描、槽位覆盖和贪心证据集选择 |
| Oracle-Page -> Region | 使用金标页面进行节点检索的诊断上界，不是可部署方法 |

MMDocIR 的 Dense 与 Hybrid 页面实验以及布局节点实验使用 BGE-M3[10]，最大序列长度为 512、批大小为 2。

## 4.4 评价指标与统计口径

对页面输出，Page Recall@K 表示前 K 个页面中至少出现一个金标页面的比例；Page MRR 是首个金标页面倒数排名的平均值；Page nDCG@K 兼顾多个金标页面及其排名。

对节点输出，Region Hit@K 表示前 K 个节点中至少出现一个金标节点的比例；Region MRR 和 Region nDCG@K 仅以金标节点计算。节点方法的页面编号可用于诊断其页面覆盖，但同一页面可能有多个返回节点，因此不将该“由节点结果诱导的页面命中”与页面方法的页面排序指标放在同一主表比较。

中文年报进一步报告规则式充分性。对于数值问题，评测检查前 K 个返回节点的文本是否共同覆盖指标、年份、单位和数值，并要求至少一个返回节点命中人工金标节点；满足两项条件的样本计为 `sufficient`。Required Item Coverage 是上述所需信息项的平均覆盖比例，Citation Mismatch 指信息项完整但未命中人工金标节点的比例。它衡量检索证据的自动化支撑条件，不等同于人工充分性评价，也不等同于最终答案正确率。

原始运行目录中充分性脚本默认检查前 5 个返回节点。为与配置中 `max_evidence_nodes=3` 的核心证据预算一致，本文对冻结预测文件进行了不改变排序、不改动任何配置的离线重评测：消融和粒度实验中的 Region Hit 与充分性指标统一以每题前 3 个返回节点计算。这里的“前 3 个”是返回排序前缀；当贪心选择提前停止时，其中可能包含用于补齐输出的高分候选，而非严格等同于全部被选中的核心节点。页面结果和节点检索主结果仍按其标准的 Top-5 排序指标报告。

## 4.5 中文年报页面检索结果

**表 4 中文年报冻结 test 集的页面检索结果（32 个问题）**

| 方法 | Page R@1 | Page R@5 | Page R@10 | Page MRR | Page nDCG@5 |
| --- | ---: | ---: | ---: | ---: | ---: |
| BM25-page | 0.1250 | 0.4375 | 0.5938 | 0.2657 | 0.2941 |
| Dense-page | 0.1562 | 0.4062 | 0.5625 | 0.2730 | 0.2919 |
| Hybrid-page | **0.1875** | **0.5938** | **0.7500** | **0.3351** | **0.3850** |

Hybrid-page 在五项页面指标上均为三种页面基线中的最高值，说明词法匹配和稠密语义信号在本划分上具有互补性。由于 test 仅有 32 个问题，本文将此结果描述为冻结划分上的观察，不进行显著性结论。

## 4.6 中文年报节点检索结果

**表 5 中文年报冻结 test 集的节点检索结果（32 个问题）**

| 方法 | Region Hit@1 | Region Hit@3 | Region Hit@5 | Region MRR | Region nDCG@5 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Page -> Region | 0.0312 | 0.2188 | 0.2500 | 0.1208 | 0.0924 |
| Hybrid-Page -> Region | 0.0312 | 0.1250 | 0.1875 | 0.0885 | 0.0615 |
| Global-Region | 0.0625 | 0.0938 | 0.1250 | 0.0859 | 0.0567 |
| **Evidence Set Region** | **0.4688** | 0.7188 | 0.8750 | 0.6104 | 0.4487 |
| Oracle-Page -> Region | 0.4062 | **0.9688** | **0.9688** | **0.6771** | **0.6390** |

在可部署方法中，Evidence Set Region 的 Region Hit@1、@3、@5、Region MRR 和 Region nDCG@5 均最高。相对于单纯的 Page -> Region，Evidence Set Region 的 Region Hit@5 从 0.2500 提升到 0.8750。Oracle-Page -> Region 的 Region Hit@5 为 0.9688，说明即使已知正确页面，仍有一个问题未能在前五个节点中命中金标节点；页面定位和页面内节点定位均仍存在改进空间。

## 4.7 Evidence Set 组件消融

**表 6 证据集组件消融结果：前 3 个返回节点的重评测（32 个问题）**

| 方法 | Region Hit@3 | Sufficiency Rate | Citation Mismatch | Required Item Coverage |
| --- | ---: | ---: | ---: | ---: |
| **Full Evidence Set** | 0.7188 | **0.6875** | 0.1875 | 0.9453 |
| w/o Hybrid-page | 0.6875 | **0.6875** | 0.1875 | 0.9375 |
| w/o Global-region | **0.7500** | **0.7188** | 0.1875 | **0.9531** |
| w/o Numeric Scan | 0.5625 | 0.5000 | 0.1563 | 0.8828 |
| w/o Slot Coverage | **0.9375** | 0.3438 | **0.0000** | 0.7734 |
| Single-node mode（不做贪心集合构造） | 0.8438 | 0.4688 | 0.0313 | 0.8359 |

数值扫描移除后，Sufficiency Rate 从 0.6875 降至 0.5000，Required Item Coverage 从 0.9453 降至 0.8828，表明数值、年份和单位等结构化线索对当前年报问题的重要性。移除槽位覆盖时，Region Hit@3 上升至 0.9375，但充分率降至 0.3438；改为 Single-node mode，即保留单节点打分而不进行贪心集合构造时，充分率为 0.4688。这一现象支持“至少一个金标节点被命中”与“返回节点共同覆盖回答所需信息”是不同目标。

另一方面，移除 Global-region 后的冻结 test 指标略高于完整方法，移除 Hybrid-page 后充分率与完整方法持平。这些结果不支持将这两个组件表述为在 test 上带来稳定增益。它们是依据 dev 集确定后被保留在最终配置中的候选来源；本文保留其 test 结果作为负面或不稳定结果，而不基于 test 回调配置。

## 4.8 节点粒度消融

**表 7 节点粒度消融结果：前 3 个返回节点的重评测（32 个问题）**

| 节点类型 | Region Hit@3 | Sufficiency Rate | Citation Mismatch | Required Item Coverage |
| --- | ---: | ---: | ---: | ---: |
| paragraph-only | 0.2500 | 0.2500 | 0.0313 | 0.7266 |
| table block-only | 0.1563 | 0.1250 | 0.4688 | 0.8828 |
| table row-only | 0.4688 | 0.0625 | 0.0938 | 0.6094 |
| **mixed-node** | **0.7188** | **0.6875** | 0.1875 | **0.9453** |

混合节点在 Region Hit@3、Sufficiency Rate 和 Required Item Coverage 上取得最高值。段落节点缺少表格数值，表格行可提升局部命中却常缺少表头、单位或上下文；表格块保留了更多字段，但 Citation Mismatch 较高，表明其文本覆盖不必然对应人工标注的精确证据节点。该结果说明不同粒度的证据具有互补性，但仅基于 32 个问题，仍需要更大规模标注验证。

## 4.9 MMDocIR 外部验证

**表 8 MMDocIR 文档内页面检索结果（1,658 个问题）**

| 方法 | Page R@1 | Page R@5 | Page R@10 | Page MRR | Page nDCG@5 | Page nDCG@10 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| BM25-page | **0.4903** | 0.7521 | 0.8456 | 0.6084 | 0.6060 | 0.6424 |
| Dense-page (BGE-M3) | 0.4451 | 0.7304 | 0.8263 | 0.5732 | 0.5708 | 0.6095 |
| Hybrid-page (BM25 + BGE-M3) | 0.4879 | **0.7600** | **0.8727** | **0.6143** | **0.6083** | **0.6520** |

Hybrid-page 在 Page R@5、Page R@10、Page MRR 和两项 nDCG 指标上最高，BM25 在 Page R@1 略高。该结果仅验证页面融合组件在公开数据上的页面覆盖与排序能力，不代表中文年报的数值规则或充分性评测已迁移到 MMDocIR。

**表 9 MMDocIR Dense 布局节点检索结果**

| 方法 | 节点输出诱导的 Page R@1 | 节点输出诱导的 Page R@5 | Region Hit@5 | Region MRR | Region nDCG@5 | Region nDCG@10 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Dense layout-node (BGE-M3) | 0.5109 | 0.7485 | 0.5044 | 0.3719 | 0.3638 | 0.3948 |

布局节点指标仅在 1,598 个有精确布局金标的问题上计算。节点输出诱导的 Page R@5 为 0.7485，而 Region Hit@5 为 0.5044，说明命中正确页面不等价于命中正确布局节点。由于节点排序中同一页面可能重复出现，该诱导页面指标只用于诊断，不与表 8 的页面排序作严格横向比较。

## 4.10 MMDocIR 问题类型分析

**表 10 MMDocIR 分类型结果摘要**

| 类型 | 问题数 | 最佳页面方法的 Page R@5 | Dense layout-node Region Hit@5 |
| --- | ---: | ---: | ---: |
| text | 502 | 0.8924 (BM25) | 0.7377 |
| figure/chart | 433 | 0.7714 (Hybrid) | 0.3259 |
| multimodal | 327 | 0.8165 (Hybrid) | 0.4677 |
| table | 183 | 0.7923 (Dense) | 0.4475 |
| metadata/web | 154 | 0.6364 (layout-node induced) | 0.3961 |

文本问题的节点定位明显优于 figure/chart 问题。图表类问题仍可能检索到相关页面，但当前系统没有图像 embedding、图表结构化解析或视觉语言模型推理，无法保证定位或理解图表内部语义。全局计数、跨页聚合和复杂表格计算同样不属于本实验已验证的能力。因此，本文将方法限定为局部文本/布局证据检索，不将其描述为通用多模态问答系统。

## 4.11 小结

冻结中文年报实验表明，Evidence Set Region 相比三种常规节点检索基线取得更高的节点命中与排序指标。以三节点证据预算重评测时，数值扫描和槽位覆盖对规则式充分性最为关键，而 Hybrid-page 与 Global-region 的 test 收益并不稳定。MMDocIR 结果进一步表明，混合页面检索可提升页面覆盖，但细粒度布局节点定位，尤其是图表和表格相关问题，仍是后续需要解决的难点。受限于中文年报 test 的 32 个问题和规则式充分性判定，本文报告的是可复核的检索观察结果，不作统计显著性、人工充分性或端到端答案质量结论。
