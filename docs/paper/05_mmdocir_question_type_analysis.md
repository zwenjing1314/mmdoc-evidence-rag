# MMDocIR 问题类型分层分析

本分析使用 MMDocIR 的 `type` 标注，将问题归为互斥类别。分类优先级为：metadata/web、figure/chart、table、layout text、multimodal、text、other。`figure/chart` 包含 Figure 或 Chart 标注，`table` 包含 Table 标注，`multimodal` 包含 multimodal-t 或 multimodal-f 标注。

## 2. 分类型结果

页面级方法不输出布局节点，因此 `Region Hit@5` 对 Dense-page 和 Hybrid-page 不适用。下表的节点指标来自 Dense layout-node；分母只包含该类别中有精确布局金标的问题。

## 3. 结论与论文范围

1. 当前布局节点方法对文本类问题最稳定，`Region Hit@5=0.7377`；这类问题适合本文的文本与布局证据检索设定。
2. 图表类问题的页面召回仍可达到 0.7021，但精确节点命中降至 0.3259。命中页面不代表理解图表内部视觉内容，因此不能将该结果解释为完整视觉问答能力。
3. 表格问题的页面定位较好，但节点命中低于文本类，说明表格拆分、行列关系和数值计算需要额外结构化处理。
4. 主论文应把任务定义为“局部文本/布局证据集检索”，将全局计数、跨页聚合、表格计算和纯视觉语义理解列为能力边界或后续工作；不应把这些问题静默排除后再声称覆盖全部 MMDocIR 问题。

本分析不改变主实验指标，仅用于解释公开集外部验证中的适用范围和错误来源。
