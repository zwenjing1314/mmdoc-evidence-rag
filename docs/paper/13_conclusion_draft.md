# 6 结论

本文面向已知所属文档条件下的中文年报问答证据定位问题，提出充分性感知的多粒度 Evidence Set Region 检索方法。该方法将页面、段落、表格块和表格行统一表示为候选证据节点，通过页面检索、全局节点检索、结构化数值扫描和封面锚点构造候选池，再利用槽位覆盖驱动的贪心过程选择互补证据。方法目标不是只返回一个语义相似节点，而是为财务事实问题提供尽可能覆盖指标、年份、数值和单位的证据集合。

在按公司划分并冻结的中文年报 test 集上，完整方法的 Page Recall@5 为 0.8750，Region Hit@5 为 0.8750，Region MRR 为 0.6104，Region nDCG@5 为 0.4487；这些节点排序指标均高于本文设置的常规可部署节点基线。为与最多 3 个核心证据节点的预算保持一致，本文对冻结预测进行 Top-3 前缀重评测，完整方法的规则式 Sufficiency Rate 为 0.6875，Required Item Coverage 为 0.9453。

消融结果表明，移除数值扫描后 Sufficiency Rate 降至 0.5000，Required Item Coverage 降至 0.8828；移除槽位覆盖后，Region Hit@3 虽升至 0.9375，但 Sufficiency Rate 降至 0.3438；不进行贪心证据集构造的 Single-node mode 的充分率为 0.4688。由此可见，节点命中率与证据充分性反映不同目标，数值线索和互补证据选择对于财务事实检索具有实际价值。但移除 Global-region 后的 test 指标略高于完整方法，Hybrid-page 的移除对充分率影响有限，因此不能将所有候选来源都表述为在当前小规模 test 上带来稳定增益。

在 MMDocIR 外部验证中，BM25 与 BGE-M3 融合的页面检索取得 0.7600 的 Page Recall@5 和 0.8727 的 Page Recall@10；Dense 布局节点检索的 Region Hit@5 为 0.5044。问题类型分析显示，文本类问题的节点定位优于 figure/chart 类问题。该外部实验验证的是页面和布局检索组件的文档内定位能力，不包含中文年报的数值槽位规则迁移，也不构成完整方法的端到端多模态问答验证。

综上，本文在有限规模的冻结数据上验证了多粒度候选与覆盖约束用于年报证据定位的可行性，并说明“命中相关节点”不能替代“证据共同覆盖回答条件”。由于 test 仅含 4 家公司和 32 个问题，充分性指标为规则式自动评测，且系统尚未接入答案生成、视觉理解或跨文档检索，本文结论应视为方法可行性和检索行为的初步证据。后续需要通过更大规模公司级数据、人工充分性审计、端到端答案评测、图表理解和效率实验进一步验证。
