# 5 讨论与局限性

## 5.1 证据集选择的作用：命中与充分性并非同一目标

中文年报的节点检索结果表明，完整 Evidence Set Region 在常规可部署节点基线中取得最高的 Region Hit@5（0.8750）、Region MRR（0.6104）和 Region nDCG@5（0.4487）。这说明由页面候选、全局节点、数值扫描和封面锚点构成的多源候选池，能够比单一路径的 Page -> Region、Hybrid-Page -> Region 或 Global-Region 更有效地定位金标节点。

更重要的是，节点命中不等价于可支撑回答。以每题前 3 个返回节点重新评测时，移除槽位覆盖后的 Region Hit@3 达到 0.9375，高于完整方法的 0.7188，但其规则式 Sufficiency Rate 仅为 0.3438；不做贪心证据集构造的 Single-node mode 也得到较高的 Region Hit@3（0.8438），但充分率仅为 0.4688。相反，完整方法的充分率为 0.6875。该结果说明，单个金标节点可能仅包含关键词、数值或局部表格行，未必同时包含指标、年度、单位和数值等回答条件。面向财务事实问题，检索目标需要从“找到一个相关片段”扩展为“返回若干可相互补充的证据”。

这一观察是本文将槽位覆盖用于证据选择的依据，但不应被表述为对所有问答任务都有效。当前槽位定义和自动检查主要对应年报中的事实型、数值型问题；复杂比较、跨表计算和需要语义推理的问答仍超出本实验所验证的范围。

## 5.2 候选来源的贡献应作区分

数值扫描在冻结 test 上表现出最清楚的作用。移除该模块后，Sufficiency Rate 从 0.6875 降至 0.5000，Required Item Coverage 从 0.9453 降至 0.8828。这与年报场景的特点一致：指标名称、报告年度、单位和数值常分散在表头、表格行和相邻文字说明中，纯语义相似度排序可能遗漏其中一项。

相比之下，Hybrid-page 与 Global-region 的收益并不稳定。移除 Hybrid-page 后的充分率与完整方法相同；移除 Global-region 后的 Region Hit@3 和充分率分别为 0.7500 与 0.7188，略高于完整方法。两项候选来源均是在 dev 集确定后被冻结，而非根据 test 调整。因此，这些结果应报告为小样本 test 上的非稳定观察，不能声称它们在最终 test 上带来确定提升。后续应在更大规模、多个公司划分或交叉验证中检验各候选来源的边际贡献。

节点粒度消融也支持混合粒度的必要性：mixed-node 的充分率为 0.6875，高于 paragraph-only（0.2500）、table block-only（0.1250）和 table row-only（0.0625）。不过表格块的 Required Item Coverage 达到 0.8828 而充分率较低，提示“文本字段出现”与“精确金标节点一致”仍是不同层面的条件。这一差异不宜简单解释为表格块无效，更可能与表格切分、金标粒度和替代性证据有关。

## 5.3 页面命中与细粒度定位的差异

MMDocIR 的布局节点实验进一步体现了粒度差异。Dense layout-node 的节点输出诱导 Page R@5 为 0.7485，而 Region Hit@5 为 0.5044。检索到正确页面只能缩小搜索范围，仍不能保证定位到正确的段落、表格或图表布局。页面内存在相似文本、相邻布局和被拆分的表格时，细粒度节点定位更困难。

这一现象说明论文中应独立报告页面级和节点级指标。节点输出产生的页面命中由前 K 个节点的页面编号诱导得到，可能包含同页重复节点，不能与直接输出 Top-K 页面的方法进行严格横向比较。中文年报中 Evidence Set Region 的页面来源与节点来源并行生成，能够减少单一两阶段路径的级联遗漏；但该设计的有效性目前仅由节点检索结果支持，不能据此推断其在大规模跨文档检索中的效果。

## 5.4 适用范围

本文研究已知所属文档条件下的文档内证据检索。系统输出排序后的页面或布局节点，供后续答案生成、人工核验或引用展示使用；系统未接入生成模型，也不报告答案正确率、幻觉率、拒答率或人工引用质量。

在 MMDocIR 分类型结果中，文本类问题的布局节点 Region Hit@5 为 0.7377，而 figure/chart 类为 0.3259。对于“文档中有多少张图”等跨页全局聚合问题，或“图中对象代表什么”等视觉语义问题，当前系统的文本和布局检索无法直接完成回答。MMDocIR 页面和布局表中虽包含 OCR/VLM 文本，但本实验没有使用图像 embedding、图表结构化解析或视觉语言模型推理。因此，本文不应被描述为通用多模态文档问答，图表理解与视觉推理也不属于已完成能力。

## 5.5 局限性与有效性威胁

本文的结论受到以下限制。

1. **样本规模有限。** 中文年报冻结 test 仅含 4 家公司和 32 个问题。当前结果适合作为固定协议下的可复核观察，不足以支持统计显著性或广泛泛化结论。后续应扩大公司、年份和问题类型，并报告置信区间或重复划分结果。
2. **充分性是规则式代理指标。** Sufficiency Rate 依赖指标、年份、单位、数值的字符串或规范化匹配，并要求返回节点与人工金标节点相交。它不能替代人工对证据可读性、推理链完整性和引用恰当性的判断；命中语义等价但节点 ID 不同的证据也可能被计为 Citation Mismatch。
3. **评测预算与核心集合不完全等价。** 系统的贪心阶段最多优先选择 3 个核心节点，但当覆盖提前完成时，输出前 3 个位置可能包含用于补齐的高分候选。本文已将充分性重评测定义为“前 3 个返回节点”，而非严格的“仅核心节点集合”。后续应在输出中明确区分核心证据和补齐候选，并单独评测两者。
4. **消融结论存在组件耦合。** 数值扫描、页面候选、全局节点候选和槽位打分共享同一候选池与排序过程。单模块移除不能完全隔离因果贡献，且 Hybrid-page、Global-region 在本 test 上未表现出稳定增益。
5. **外部验证并非完整方法迁移。** MMDocIR 使用 BGE-M3 验证页面和布局节点检索组件，而中文年报主实验使用 BGE-small-zh-v1.5，并包含未迁移的数值扫描、槽位定义和充分性评测。因此，外部结果只能说明基础检索组件在公开数据上的行为，不能证明完整 Evidence Set Region 已在 MMDocIR 上得到端到端验证。
6. **检索范围和效率尚未覆盖部署条件。** 本文假定问题所属文档已知，未测量跨文档召回、索引更新、不同硬件上的吞吐量或端到端延迟。现有运行日志可用于定位耗时，但尚未形成可比较的效率实验。

## 5.6 后续工作

后续工作可沿三条路径推进。第一，扩展公司级年报数据和人工证据标注，并用多次公司划分、人工充分性审计和置信区间评估检验结果的稳定性。第二，区分并显式输出核心证据和补齐候选，将证据集选择与受约束答案生成结合，分别评估答案正确性、引用一致性与拒答行为。第三，针对图表、全局计数和复杂表格问题，引入图表解析、视觉特征、视觉语言模型及文档级聚合模块，并在跨文档检索和效率条件下评估系统。
