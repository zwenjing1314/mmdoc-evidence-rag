# 1 引言

上市公司年度报告包含财务指标、经营分析、风险提示和审计说明等大量异构信息，是面向金融分析、监管辅助和投资研究的重要信息源。围绕年报开展问答时，用户通常不仅需要一个数值或事实性结论，还需要能够核验的来源证据。例如，回答“某公司某年度的营业收入是多少”时，可靠证据应尽可能同时包含指标名称、报告年度、数值、单位及其所在位置。由于年报篇幅长、页面结构复杂，且关键信息常分散于正文段落、财务报表和表格行中，如何检索能够充分支撑回答的证据仍是文档问答系统面临的关键问题。

检索增强生成及文档问答研究通常采用段落级或页面级检索，为下游回答提供相关上下文[引用待补]。页面级检索保留了较完整的版面和语境，但页面中往往包含大量无关内容，难以给出精确引用；细粒度节点检索能够定位局部片段，却可能遗漏表格标题、单位或跨节点的补充信息。尤其对于财务数值问题，单个相关节点命中并不意味着所返回证据足以支撑回答：高相似度节点可能仅出现指标名称，数值、年份和单位仍位于其他表格行或相邻段落中。因此，仅以页面召回率或单节点命中率作为优化目标，难以直接反映证据是否完整、可核验。

为解决上述问题，本文聚焦**已知问题所属文档条件下**的中文年报问答证据检索，提出一种充分性感知多粒度证据集检索方法（Evidence Set Region）。该方法将页面、段落、表格块和表格行统一建模为混合粒度证据节点；通过混合页面检索、全局节点检索、结构化数值扫描和封面锚点生成候选集合；再围绕指标、年份、数值、单位和引用等信息槽位，以覆盖感知的贪心策略选择紧凑且互补的多节点证据集。为评估检索结果是否具备回答支撑条件，本文在评测阶段构建规则式充分性检查，统计所需信息项覆盖和引用一致性。

本文在按公司划分且冻结的中文年报测试集上进行实验，并在 MMDocIR 公开集上完成页面级和布局节点级外部验证。中文年报实验表明，完整方法的 Page Recall@5、Region Hit@5 和 Sufficiency Rate 均达到 0.8750；消融实验显示，数值扫描和槽位覆盖对证据充分性具有关键作用，单节点选择虽然能取得更高的区域命中率，却难以提供完整支撑。MMDocIR 实验进一步显示，混合页面检索在 Page Recall@5 上达到 0.7600；但图表类问题的节点定位效果明显低于文本类问题，说明视觉语义理解和全局聚合仍是当前方法的能力边界。

本文的主要贡献如下：

1. 提出面向中文年报问答的充分性感知多粒度证据集检索框架，将页面、段落、表格块和表格行纳入统一证据表示，并从“检索单个相关节点”转向“构造互补证据集”。
2. 设计多源候选生成与槽位覆盖感知的贪心选择机制，将混合页面检索、全局节点检索和结构化数值扫描结合起来，优先补足指标、年份、数值和单位等回答所需信息。
3. 构建公司级冻结测试和规则式证据充分性评测，并通过节点粒度、候选来源和选择策略消融验证充分证据集的有效性；同时在 MMDocIR 公开集上报告页面、布局节点及问题类型分层结果，明确方法的适用范围与局限性。

本文其余部分安排如下：第 2 节介绍相关工作；第 3 节描述所提方法；第 4 节给出实验设置、对比结果与分析；第 5 节讨论局限性；第 6 节总结全文。
